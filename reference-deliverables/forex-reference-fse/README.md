# Forex Reference FSE

Installable WordPress block theme based on the supplied Forex Trade Technology HTML export and screenshot.

## Install

1. Upload `forex-reference-fse.zip` in **Appearance → Themes → Add New → Upload Theme**.
2. Activate **Forex Reference FSE**.
3. Open **Appearance → Editor** to edit the homepage, header, footer, typography presets, and spacing presets.
4. Add local pages for `/solutions` and `/contact`, or change the CTA URLs in the Site Editor.

The theme uses the reference's Inter/Manrope font families and emerald/mint palette. Google Fonts supplies the font files in this portable starter; for a self-hosted-only deployment, replace the import in `assets/css/theme.css` with local WOFF2 files.
